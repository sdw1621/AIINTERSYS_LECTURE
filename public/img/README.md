# public/img

「클로드 코드 순한맛」 과정 페이지(/claude-code)에서 쓰는 이미지 폴더입니다.

## 넣어야 할 파일

| 파일명 | 용도 | 권장 규격 |
| --- | --- | --- |
| `cc-hero.jpg` | 히어로 우측 비주얼 (떠 있는 터미널 창) | 가로 1100px 내외, 16:9 |
| `cc-og.jpg` | 링크 공유 썸네일 (앰버 글로우) | 1200×630 고정 |
| `cc-desk.jpg` | 준비물 섹션 보조 이미지 (책상 위 노트북) | 가로 900px 내외 |

## 넣은 뒤 할 일

`src/lib/claude-code-course.ts` 의 `CDN` 상수를 지우고
`HERO_IMAGE.src` / `OG_IMAGE.src` 를 `/img/cc-hero.jpg`, `/img/cc-og.jpg` 로
바꾸면 됩니다. 그 외 코드는 손댈 필요가 없습니다.

## 현재 상태

이미지는 아직 이 폴더에 없고, Higgsfield CDN 주소를 참조하고 있습니다.
이 세션의 네트워크 정책이 해당 CDN 도메인을 차단해 파일을 내려받지
못했습니다. 파일을 이 폴더에 커밋하면 위 경로만 바꿔 외부 의존을 없앨 수
있습니다.
